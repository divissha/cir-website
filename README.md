# CIR Website — React + Vite + Tailwind

Academic visual foundation for the Centre for Intelligent Robotics (CIR), IIIT Allahabad.

## Stack
- React
- Vite
- Tailwind CSS v4
- Lucide React

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Add images

Place these files in `public/images/`:
- robot-hero.png
- campus.jpg
- event-1.jpg
- event-2.jpg
- event-3.jpg

The content is intentionally placeholder-oriented so the existing CIR content can be plugged in later.

- Navbar
